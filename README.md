# Vehicle Service Management System

## Project Overview
The Vehicle Service Management System is a MySQL-based database project designed to manage vehicle servicing operations. It helps maintain customer details, vehicle information, mechanic records, service bookings, service tasks, and spare parts.

## Objectives
- Manage customer and vehicle information.
- Maintain mechanic and service details.
- Track vehicle service bookings.
- Manage spare parts and their costs.
- Generate reports using SQL queries.
- Analyze service revenue and business performance.

## Technologies Used
- Database: MySQL
- Tool: MySQL Workbench
- Language: SQL

## Database Tables
- customers
- vehicles
- mechanics
- service_types
- parts
- service_bookings
- service_tasks
- booking_parts

## SQL Concepts Covered
- DDL – CREATE, ALTER, DROP, TRUNCATE
- DML – INSERT, UPDATE, DELETE
- DQL – SELECT
- DCL – GRANT, REVOKE
- TCL – COMMIT, ROLLBACK, SAVEPOINT
- Aggregate Functions – SUM, COUNT, AVG, MIN, MAX
- Joins – INNER JOIN, LEFT JOIN, RIGHT JOIN
- Subqueries
- GROUP BY and HAVING
- String and Date Functions
- CASE Statements
- Window Functions
- Common Table Expressions (CTEs)
- Data Cleaning
- Business Analysis and KPI Reports

## Key Features
- Customer and vehicle management
- Mechanic assignment
- Service booking management
- Spare parts tracking
- Revenue analysis
- Service performance reports

## How to Run the Project
1. Install MySQL Server and MySQL Workbench.
2. Clone this repository:
   ```bash
   git clone https://github.com/Yaashiiikaa/Vehicle_Service_Management_SQLProject.git
   ```
3. Open MySQL Workbench.
4. Open `Vehicle_Service_Management.sql`.
5. Execute the SQL script.
6. Explore the tables and execute the queries.
